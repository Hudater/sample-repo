# sample-repo

```
sample-repo/
├── docs/
│   ├── overview.md
│   ├── getting-started.md
│   ├── api/
│   │   ├── introduction.md
│   │   ├── endpoints.md
│   │   └── authentication.md
│   └── guides/
│       ├── quickstart.md
│       └── advanced.md
├── src/
│   ├── README.md
│   ├── components/
│   │   └── README.md
│   └── utils/
│       └── README.md
└── tests/
    └── README.md
```
