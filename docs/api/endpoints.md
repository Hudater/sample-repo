# API Endpoints

A list of all available API endpoints.

## Files

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/files` | List all files |
| `GET` | `/files/:id` | Get a specific file |
| `POST` | `/files` | Create a new file |
| `PUT` | `/files/:id` | Update a file |
| `DELETE` | `/files/:id` | Delete a file |

## Directories

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/directories` | List all directories |
| `GET` | `/directories/:id` | Get a specific directory |
| `POST` | `/directories` | Create a new directory |
| `PUT` | `/directories/:id` | Update a directory |
| `DELETE` | `/directories/:id` | Delete a directory |
